Lingua AI — Offline Admin Provisioning

Security: This page is a local-only helper. Download this HTML file and open it from your computer while offline. It has no network requests. Never share the generated password hash, TOTP secret, encryption key, or SQL output.

1. Cloudflare Worker secret

Add this value as the Worker Secret named TOTP_ENCRYPTION_KEY. Keep it safe; it is needed to decrypt the authenticator secret.

2. Authenticator app

Scan/import the URI in your authenticator app. If your app does not support URI import, use the displayed Base32 secret.

3. D1 provisioning SQL

First add the encryption key in Cloudflare, then run this SQL once in the correct D1 database. Verify the email before running. The script creates an active admin account, password hash, policy, unverified TOTP factor and audit event. It does not mark TOTP verified.

After running SQL, complete TOTP verification through a secure enrollment flow before using Password + TOTP. This current release does not yet provide that enrollment screen; do not manually mark the factor verified without confirming a live authenticator code.
